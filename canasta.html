Network relay

Advanced settings ▾

A direct connection works when both players are on the same network, or neither is behind a strict firewall. If a connection just hangs at "Connecting…", the host setting this up is normally enough to fix it — the other player usually doesn't need to do anything here. How do I get one? ▾

Sign up for a free account at metered.ca (no credit card) and create a TURN credential from their dashboard — it gives you a server URL, username, and password meant to be used right in an app like this one. Since this game only ever sends small text messages, never audio or video, even their smallest free tier comfortably covers a lot of games. Paste what they give you below; it's saved on this device only, so you'll only need to do this once.

Only the host normally needs to do this — a relay offered by either side is usually enough for both players to connect through it, and firewalls almost always allow the outbound connection needed to reach it. If connections still fail with only the host configured (rare), the other player can add their own here too. If port 80 doesn't work, try the same address with :443 instead — it blends in as ordinary web traffic and gets through stricter firewalls more often.

Hosting from more than one device? Generate a snippet from what's filled in above, and paste it into the file once — every device using that copy will have it automatically, no re-entering per browser.

Paste this as the value of EMBEDDED_TURN_DEFAULT near the top of the file's script — search for that name to find it.
